KEY FINDINGS
================================================================================

Complex Multiplication Hotspot:
  - 4 multiplications + 2 additions per operation
  - Heavy use in FFT butterflies
  - NEON speedup potential: 2-4x

Lookup Tables:
  - Total: ~1.5 MB working set
  - trig16: 256 KB (65536 entries)
  - Constellation: 390 KB (256x256)
  - Rotators: 512 KB (separate sin/cos)

No CORDIC Implementation:
  - Lookup tables preferred (O(1) access)
  - Floating-point math libs used
  - Smart design for FPU platforms

Vectorization Opportunities:
  - Conservative estimate: 1.5-2x with compiler flags
  - With NEON optimization: 3-5x on DSP-heavy code
  
  CRITICAL (2-4x speedup):
    1. FFT butterflies
    2. Phase rotation
    3. RMS power accumulation
    4. Magnitude + min/max tracking

Fixed-Point Strategy:
  - Angles: 16-bit (u_angle, s_angle)
  - Inputs: floating-point IQ
  - Outputs: fixed-point metrics/phase
  - Efficient for real-time processing
