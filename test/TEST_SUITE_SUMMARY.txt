   - Uses vmlaq_f32 (multiply-accumulate) intrinsics
   - vld2q_f32 for efficient interleaved I/Q loading

================================================================================
TROUBLESHOOTING
================================================================================

Q: Tests build but show "NEON not available"?
A: This is expected on x86. Tests validate scalar fallback works correctly.
   To test NEON, build on ARM or use cross-compiler.

Q: Tests fail with large errors?
A: Check compiler optimization level. Try -O2 instead of -O3.
   Floating-point differences should be < 1e-5.

Q: Speedup less than expected?
A: - Check CPU frequency scaling (set governor to "performance")
   - Run on idle system (no background processes)
   - Verify NEON instructions in binary: make check-neon

Q: Cross-compilation fails?
A: Install ARM toolchain: sudo apt-get install g++-arm-linux-gnueabihf
   Then: make cross-arm
