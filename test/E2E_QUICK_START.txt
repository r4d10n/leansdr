================================================================================
TROUBLESHOOTING
================================================================================

Problem: "leandvb not found"
Solution:
  cd /home/user/leansdr && make
  Ensure binaries exist in src/apps/

Problem: "ModuleNotFoundError: No module named 'numpy'"
Solution:
  pip3 install numpy
  # or: sudo apt-get install python3-numpy

Problem: Low speedup (<1.5x)
Causes:
  • NEON not compiled in (check with: nm leandvb | grep neon)
  • CPU throttling (set governor to performance)
  • Not running on ARM (NEON is ARM-specific)
  • Small test size (overhead dominates)

Problem: High BER or comparison fails
Causes:
  • Low SNR (increase --snr parameter)
  • Incorrect sample rate
  • NEON implementation bug (file issue)

Problem: "bash: bc: command not found"
Solution:
  sudo apt-get install bc

ADVANCED USAGE
================================================================================

Custom Test Parameters:
  Edit test_e2e_neon.sh and add to TEST_CONFIGS array:

  TEST_CONFIGS[my_test]="symbol_rate=3000000 sample_rate=7200000 \
                         snr=10 packets=250 format=f32"

  Then run: ./test_e2e_neon.sh my_test

Manual Pipeline:
  # Generate signal
  ./generate_test_signal.py -o test.iq --num-packets 100

  # Process with scalar
  cat test.iq | leandvb --f32 -f 2400000 --sr 1000000 > scalar.ts

  # Process with NEON
  cat test.iq | leandvb_neon --f32 -f 2400000 --sr 1000000 > neon.ts

  # Compare
  ./compare_outputs.py scalar.ts neon.ts --verbose

JSON Output:
  ./compare_outputs.py scalar.ts neon.ts --json > results.json
